# Dataflow reference assets

- [Pipeline matrix](auto-pipeline-matrix.html): static visualization retained for
  reading and design reference.
- [Prototype notes](prototype-reference.md): historical design and experiment
  context, including commands and paths from the prototype revision. Use the
  current [architecture](../../docs/architecture.md) and
  [verification guide](../../docs/verification.md) for maintained APIs and commands.

These assets are outside the production Python package and do not participate in
compilation, installation or test execution.
